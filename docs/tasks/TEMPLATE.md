# TASK-ID: Short observable outcome

- Status: Ready / In progress / Blocked / Done
- Owner: To be assigned
- Dependencies: Task IDs and provider/environment prerequisites
- Relevant ADRs: Link authoritative decisions

## Scope

Describe the smallest useful vertical result and what remains outside it.

## Acceptance criteria

Describe externally observable behavior, failure behavior, and required invariants.

## Validation plan

Identify deterministic checks, builds, provider calls, datasets, budget, and environment. Planned commands are not evidence of execution.

## Evidence and handoff

Record actual commands/results, tested versions, artifacts, changed contracts, and unresolved limitations. Never include secrets.
